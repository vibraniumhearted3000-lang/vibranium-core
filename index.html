THE CORE

VIBRANIUM CORE is an original, unofficial fan-made mini-game experience. It uses its own visual language, interface, effects and code rather than official movie artwork, characters, fonts, logos or music.

Built as a lightweight single-file project so it can be published directly through GitHub Pages.
